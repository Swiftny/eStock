# Skip navigation visibility verification

24 October 2026. Local change on top of PR 12 (`5b3e068`).

## Change and scope

The user reported "Skip to content" becoming visible when pulling the landing page down. Previously the link was moved above the viewport with a transform. Its inactive state now also has `clip-path: inset(50%)`, which leaves no painted area to expose. `:focus-visible` restores the complete link and its existing focus ring. The existing anchor and main-content focus target remain.

Frontend scope, with one coordinated editor for shared `src/app/globals.css`, `PROJECT_CONTEXT.md`, the tools declaration and this report. The scope map does not list the shared global stylesheet or evidence files; verification uses this explicit four-file allowlist and does not claim a single-area checker pass. Starting Git status was clean. No new dependency, visual asset, API, database or permission behavior was introduced.

Design read: the existing eStock landing for shop Managers and Staff, using its blue/Manrope identity and ENERGY 2 / RHYTHM 2 / MOTION 2. The clipping removes an unintended visual exposure while keeping the keyboard shortcut available. Existing layout, typography, palette and motion remain appropriate for this focused correction.
